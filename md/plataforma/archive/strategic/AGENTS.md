## Project

Felipe Santander Professional Platform

Stack:

- Next.js
- React
- TypeScript
- TailwindCSS

---

# Mission

This project is NOT a portfolio.

It is a professional positioning platform.

Its purpose is to increase the perceived strategic value of Felipe Santander.

---

# Primary Goal

Every implementation must reinforce one message:

Felipe delivers everything expected from a Senior Product Designer.

His differentiator is integrating Product, Business and Engineering to solve complex organizational problems.

Never reduce Felipe to a UI or UX Designer.

---

# Source of Truth

Documents precedence:

1. 00-Brand-Operating-System.md
2. Brand Constitution
3. Product Constitution
4. Active Case Master Document
5. Active Acceptance Checklist
6. Strategic Log
7. Existing implementation

Never contradict higher precedence documents.

---

# Engineering Principles

Prefer refactoring over rewriting.

Prefer composition over duplication.

Prefer reusable components.

Avoid unnecessary dependencies.

Always preserve accessibility.

Never break responsive behavior.

---

# Narrative Principles

Do not write marketing copy.

Do not exaggerate achievements.

Do not invent metrics.

Do not invent responsibilities.

Do not use buzzwords without context.

Always focus on organizational transformation.

Products are consequences.

Problems are protagonists.

---

# UX Principles

Every section must answer:

"What organizational problem does this solve?"

Never:

"Look how beautiful this interface is."

---

# Components

Reuse before creating.

Document every new component.

Keep naming consistent.

---

# Git Workflow

Never commit directly to main.

Always create branches.

Always explain changes.

Always keep implementation logs updated.

---

# Documentation

Every implementation must update:

07-strategic-log-antigravity.md

(or future Codex strategic log)

---

# Cases

Every case derives from its Master Document.

Never create narrative directly from screenshots.

Never infer missing information.

---

# Acceptance

Build passes.

Lint passes.

Responsive passes.

Accessibility preserved.

Narrative aligned.

No fabricated content.

---

# Definition of Done

Implementation finished.

Documentation updated.

Build successful.

No regression.

Ready for Product Owner review.
