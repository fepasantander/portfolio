# UI-004 — VitruChat Case Editorial Redesign

Version: 1.0

Status: Approved

Priority: Critical

Type:
UI Polish
Editorial Design
UX Refinement

---

# Objetivo

Reprojetar exclusivamente a experiência visual e editorial da página:

/cases/vitruchat

Esta Sprint NÃO altera:

- Home
- Header
- Footer
- Journal da Home
- Cards da Home
- Pipeline
- Tipos
- Arquitetura
- SEO
- Analytics

O objetivo é transformar o Case em uma leitura agradável, altamente escaneável e visualmente memorável.

---

# Problema Atual

A página possui bom conteúdo, porém apresenta:

- baixa hierarquia visual;
- excesso de blocos semelhantes;
- pouco contraste entre seções;
- títulos sem destaque;
- leitura cansativa;
- ritmo visual repetitivo.

O visitante percebe uma documentação.

O objetivo é transmitir uma publicação premium de Product Design.

---

# Hero

Utilizar como imagem principal:

Pastas_MenuClosed&PropOpen&PromptOpen

(v2-light)

A Hero deve conter:

Categoria

Empresa

Produto

Ano

Resumo executivo

Meu papel

Tecnologias

Overlay discreto.

Tipografia forte.

Grande impacto visual.

---

# Hierarquia

Cada seção deverá possuir identidade própria.

Exemplo:

Problema

↓

Solução

↓

Resultados

↓

Evidências

↓

Product Transformation Journal

Evitar sensação de blocos repetidos.

---

# Tipografia

Criar níveis claros.

Título principal.

Título de seção.

Subtítulo.

Texto.

Legenda.

Destaques.

Utilizar respiro generoso.

---

# Escaneabilidade

Destacar visualmente:

- números;
- métricas;
- tecnologias;
- responsabilidades;
- decisões importantes.

Utilizar:

chips

callouts

listas curtas

ícones discretos

Não utilizar grandes blocos contínuos de texto.

---

# Resultados

Caso existam indicadores importantes:

destacar em cards.

Evitar esconder resultados dentro de parágrafos.

---

# Evidências

Transformar em galeria navegável.

Adicionar:

- seta anterior;
- próxima;
- teclado;
- swipe;
- indicadores.

Utilizar apenas as melhores telas.

---

# Product Transformation Journal

Transformar em uma seção editorial.

Adicionar contexto.

Explicar claramente:

O Case mostra o resultado.

O Journal mostra o processo.

O CTA deve ser visualmente forte.

---

# Navegação

Adicionar:

← Voltar para Home

Logo abaixo da Hero.

No final da página:

Próximo passo

↓

Explorar o Product Transformation Journal

Com texto explicativo.

Não apenas um link.

---

# Motion

Adicionar apenas:

fade

hover

transições curtas

Jamais utilizar animações chamativas.

---

# Critérios de Aceitação

✓ Hero redesenhada.

✓ Hierarquia editorial evidente.

✓ Melhor escaneabilidade.

✓ Evidências navegáveis.

✓ CTA do Journal atrativo.

✓ Voltar para Home.

✓ Layout premium.

✓ Nenhuma alteração fora de /cases/vitruchat.
