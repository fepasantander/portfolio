Status: Approved

Type:
Creative Direction

---

# Objetivo

Elevar significativamente a percepção de qualidade do Portfolio.

Após EV-001 e EV-002, a arquitetura está correta, porém a direção de arte ainda transmite a sensação de uma aplicação construída com componentes genéricos.

O objetivo desta Sprint NÃO é alterar a arquitetura.

Também NÃO é alterar conteúdo.

O objetivo é aumentar percepção de:

• senioridade;

• sofisticação;

• clareza;

• identidade visual;

• experiência premium.

O resultado esperado é que um recrutador ou Head perceba imediatamente que o Portfolio foi concebido por um Product Designer Sênior.

# Referências

A direção de arte deve se inspirar em produtos como:

- Stripe
- Linear
- Vercel
- Notion
- Raycast
- Figma

Não copiar layouts.

Inspirar-se apenas em:

• ritmo;

• tipografia;

• hierarquia;

• uso de espaço;

• microinterações;

• editorial.

---

# Linguagem Visual

A Home não deve parecer uma Landing Page.

Ela deve parecer uma publicação editorial sobre transformação de produtos.

Cada seção precisa possuir identidade própria.

Evitar repetição de layouts.

---

# Paleta

Continuar utilizando a identidade já definida.

Cores principais:

Cyan

Magenta

Yellow

As cores deverão ser utilizadas apenas para criar pontos de atenção.

Nunca competir com o conteúdo.

---

# Empresas

Problema

Os logos desaparecem.

Solução

Cada logo passa a ocupar um Logo Cell.

Características

- superfície neutra;

- padding generoso;

- contraste garantido;

- borda discreta;

- hover elegante;

- nenhuma animação chamativa.

Todos os logos devem permanecer totalmente legíveis.
