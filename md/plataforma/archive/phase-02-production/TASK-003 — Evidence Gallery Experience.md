# TASK-003 — Evidence Gallery Experience

Status: Ready

Priority: Critical

Type:
UI
UX
Interaction Design

Objetivo

Transformar exclusivamente a seção "Evidências" da página:

/cases/vitruchat

Nenhuma outra área deverá ser alterada.

---

Escopo

Modificar apenas:

- Galeria de Evidências
- Navegação da Galeria

Não alterar:

- Hero
- Journal
- Home
- Cards
- Pipeline
- Navegação geral

---

Problema

As evidências atualmente são apresentadas de forma linear.

Isso dificulta compreender rapidamente a evolução do produto.

A experiência deve lembrar uma apresentação de produto.

---

Implementação

A galeria deverá funcionar como um Carousel de Produto.

Cada imagem deverá ocupar posição de destaque.

---

Navegação

Adicionar:

← anterior

próxima →

Indicadores inferiores.

Exemplo:

● ○ ○ ○ ○ ○ ○

Permitir navegação:

- mouse
- touch
- teclado

---

Imagem

Cada screenshot deverá utilizar o maior espaço possível sem comprometer a leitura.

Manter proporção.

Não cortar interfaces.

---

Legenda

Layout

Microinterações

Adicionar apenas:

fade

slide

transição curta

hover discreto nas setas.

Jamais utilizar animações chamativas.

Responsividade

Desktop

Imagem ampla.

Tablet

Imagem centralizada.

Swipe prioritário.
