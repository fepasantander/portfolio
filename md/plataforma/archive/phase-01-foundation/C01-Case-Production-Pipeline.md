# Objetivo

Padronizar a produção de todos os Cases do Portfolio.

Este documento define o fluxo editorial utilizado desde a coleta de informações até a publicação.

Nenhum Case deverá ser escrito diretamente.

Todo Case nasce deste pipeline.

# Critérios de Aprovação

Cada Case deve responder claramente:

Qual era o problema?

Qual foi meu papel?

Como resolvemos?

Qual impacto foi gerado?

O que aprendi?

Se alguma resposta estiver fraca:

o Case retorna para revisão.
