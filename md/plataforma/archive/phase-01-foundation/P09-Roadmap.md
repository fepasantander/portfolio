# Felipe Santander — Portfolio

# P09 — Product Roadmap

Version: 1.0

Status: Approved

---

# Objetivo

Definir a evolução do Portfolio como um produto digital.

O Roadmap orienta prioridades.

Não representa uma lista de funcionalidades.

Cada etapa deve gerar valor perceptível para recrutadores e gestores.

---

# Princípios

Priorizar:

• Valor entregue

• Simplicidade

• Performance

• Conteúdo

• Escalabilidade

Adiar:

• Funcionalidades experimentais

• Customizações complexas

• Efeitos visuais

• Integrações desnecessárias

---

# Definição de MVP

O MVP deve ser suficiente para gerar entrevistas.

Nada além disso é obrigatório para o primeiro lançamento.

---

# MVP (v1.0)

Objetivo

Publicar o Portfolio.

Entregas obrigatórias

✓ Home

✓ Sobre

✓ Cases

✓ Página individual de Case

✓ Contato

✓ Journal

✓ Responsividade

✓ SEO

✓ Analytics

✓ Performance

✓ Deploy

Critério de sucesso

Portfolio online e compartilhável.

---

# Versão 1.1

Objetivo

Fortalecer credibilidade.

Entregas

• Mais Testimonials

• Melhorias de copy

# Versão 1.2

Objetivo

Ampliar profundidade técnica.

Entregas

• Cross-linking entre Cases
