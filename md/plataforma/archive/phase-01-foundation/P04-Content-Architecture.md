# Felipe Santander — Portfolio

# P04 — Content Architecture

Version: 1.0

Status: Approved

---

# Objetivo

Definir toda a arquitetura de conteúdo do Portfolio.

Este documento especifica:

- todas as seções;
- todos os componentes;
- hierarquia dos textos;
- organização visual;
- padrão dos Cases.

---

# Filosofia

O usuário deve compreender cada seção em poucos segundos.

Cada bloco responde uma única pergunta.

Nada mais.

---

---

# Critérios de Aceite

✓ Toda Home pode ser percorrida em menos de cinco minutos.

✓ Todos os Cases possuem exatamente a mesma estrutura.

✓ Nenhum bloco compete visualmente com outro.

✓ Testimonials funcionam como prova social.

✓ Journal permanece como aprofundamento.

✓ Conteúdo organizado para leitura rápida.
