# P03 — Information Architecture

Version: 1.0

Status: Approved

---

# Objetivo

Definir toda a arquitetura de informação do Portfolio.

Este documento estabelece:

- navegação;
- hierarquia;
- fluxo do usuário;
- organização dos conteúdos;
- relação entre Portfolio e Product Transformation Journal.

Nenhuma implementação deverá contrariar este documento.

---

# Filosofia

O visitante nunca deve se perguntar:

"Para onde vou agora?"

Cada seção deve conduzir naturalmente para a próxima.

A navegação deve ser praticamente invisível.
